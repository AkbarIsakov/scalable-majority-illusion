# Data

The experiments use the public **Instagram 70K** dataset.

The raw dataset is not included in this repository.

Dataset:
https://www.kaggle.com/datasets/krpurba/im-instagram-70k

After downloading, place the required files into this directory.

Expected files:

- `Network for IC LT.txt`
- `Network for IC-u LT-u.txt`
- `Instagram User Stats.csv`

The preprocessing steps are described in
`notebooks/majority_illusion_experiments.ipynb`.
